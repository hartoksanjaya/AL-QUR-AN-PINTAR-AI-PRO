📜 Kebijakan Privasi

Kebijakan Privasi ini menjelaskan bagaimana aplikasi dan website Al Qur'an Pintar AI mengumpulkan, menggunakan, dan melindungi informasi pengguna.

1. Informasi yang Dikumpulkan

Kami tidak mengumpulkan data pribadi sensitif seperti nama, alamat, atau informasi identitas lainnya secara langsung.

Namun, aplikasi dapat menggunakan layanan pihak ketiga yang secara otomatis mengumpulkan data non-pribadi seperti:

- Data penggunaan aplikasi
- Informasi perangkat
- Statistik performa

2. Penggunaan Informasi

Informasi yang dikumpulkan digunakan untuk:

- Meningkatkan kualitas layanan
- Memperbaiki performa aplikasi
- Menyediakan fitur yang lebih baik

3. Cookie dan Teknologi Pelacakan

Website dapat menggunakan cookie untuk meningkatkan pengalaman pengguna. Anda dapat menonaktifkan cookie melalui pengaturan browser Anda.

4. Layanan Pihak Ketiga

Aplikasi ini menggunakan API pihak ketiga seperti:

- API Al-Qur’an untuk data ayat dan audio
- Layanan browser untuk fitur suara (voice recognition)

5. Keamanan Data

Kami berkomitmen untuk menjaga keamanan data pengguna. Namun, perlu diketahui bahwa tidak ada metode transmisi data melalui internet yang 100% aman.

6. Tautan ke Situs Lain

Website ini dapat berisi tautan ke situs lain. Kami tidak bertanggung jawab atas kebijakan privasi situs tersebut.

7. Perubahan Kebijakan

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu tanpa pemberitahuan terlebih dahulu.

8. Persetujuan

Dengan menggunakan layanan ini, Anda dianggap telah menyetujui Kebijakan Privasi ini.
