🔒 Kebijakan Privasi

Aplikasi Al Qur'an Pintar AI berkomitmen untuk menjaga privasi pengguna. Kami menghormati dan melindungi data Anda.

1. Tidak Ada Pengumpulan Data Pribadi

Aplikasi ini tidak mengumpulkan, menyimpan, atau membagikan data pribadi pengguna.

  • Tidak ada pendaftaran akun
  • Tidak ada pengumpulan nama, email, atau identitas
  • Tidak ada pelacakan aktivitas pengguna secara pribadi

2. Pemrosesan oleh Pihak Ketiga

Aplikasi ini menggunakan layanan pihak ketiga untuk menyediakan fitur seperti:

  • Audio murottal (streaming)
  • Data ayat Al-Qur’an
  • Fitur pengenalan suara (voice command)

Saat menggunakan fitur tersebut, pihak ketiga dapat secara otomatis memproses data teknis seperti alamat IP atau koneksi jaringan. Kami tidak mengontrol atau menyimpan data tersebut.

3. Penyimpanan Lokal

Aplikasi dapat menyimpan data secara lokal di perangkat Anda, seperti:

  • Bookmark ayat terakhir
  • Preferensi pengguna (qori, dll)

Data ini tidak dikirim ke server mana pun.

4. Cookie dan Teknologi Serupa

Website ini dapat menggunakan cookie untuk fungsi dasar. Cookie ini tidak digunakan untuk pelacakan pribadi.

5. Keamanan

Karena kami tidak mengumpulkan data pribadi, risiko kebocoran data sangat minimal. Namun, kami tetap menjaga keamanan sistem aplikasi.

6. Privasi Anak

Aplikasi ini aman digunakan oleh semua usia dan tidak mengumpulkan data dari anak-anak.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan ditampilkan di halaman ini.

8. Persetujuan

Dengan menggunakan aplikasi ini, Anda menyetujui kebijakan privasi ini.
